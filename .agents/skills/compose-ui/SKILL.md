# compose-ui

Для компонента с визуальным содержимым ставь `modifier: Modifier = Modifier` первым опциональным параметром, после обязательных. Передавай полученный `modifier` корневому элементу ровно один раз.

Разделяй экран на `Screen` и `Content`. В `Screen` получай `ViewModel`, собирай `uiState` через `collectAsStateWithLifecycle()` и передавай состояние и обработчик событий в `Content`. В `Content` отображай переданные данные и сообщай о действиях через callback. Например, при вводе веса порции отправь новое значение владельцу состояния. Расчёт калорий оставь за пределами верстки.

Добавь функцию с `@Preview`, которая вызывает `Content` внутри темы приложения с фиксированным примером состояния. Выбирай семантически связанные роли `MaterialTheme.colorScheme`, например `surface` и `onSurface`, а текст оформляй через `MaterialTheme.typography`.
